******************** Design WhatsApp Chat UI *******************************

1. Start by clarifying the requirements:
----------------------------------------
    Functional requirements
            Users should be able to:
                - View a list of chats
                - Open a conversation
                - Send messages
                - Receive messages in real time
                - Send images/files
                - See typing indicators
                - See online/offline status
                - See message status
                - Sending
                - Sent
                - Delivered
                - Read
                - Load older messages
                - Search chats
                - Receive notifications


2. Simple YouTuber-style system design diagram:
-----------------------------------------------
    This is the kind of diagram I would draw first:
                    ┌───────────────────┐
                    │       USER        │
                    │   WhatsApp UI     │
                    └─────────┬─────────┘
                              │
              ┌───────────────┴───────────────┐
              ▼                               ▼
     ┌─────────────────┐             ┌─────────────────┐
     │   REST APIs     │             │    WebSocket    │
     │                 │             │                 │
     │ Chats           │             │ New Message     │
     │ Old Messages    │             │ Typing          │
     │ Media Upload    │             │ Online Status   │
     └────────┬────────┘             └────────┬────────┘
              │                               │
              └───────────────┬───────────────┘
                              ▼
                     ┌────────────────┐
                     │    BACKEND     │
                     │                │
                     │ Chat Service   │
                     │ Message DB     │
                     └────────────────┘

    The key idea:
            - REST API = initial data + historical data
            - WebSocket = live updates
            
    This is the core of the entire design.

4. The Data Flow:
-----------------
    This is probably the most important diagram to understand.
                            OPEN CHAT
                               │
                               ▼
                        ┌──────────────┐
                        │ GET Messages │
                        └──────┬───────┘
                               │
                               ▼
                        ┌──────────┐
                        │ REST API │
                        └────┬─────┘
                             │
                             ▼
                        Initial Messages
                             │
                             ▼
                        ┌──────────────┐
                        │ Message List │
                        └──────────────┘
                --------------------------------

                    NEW MESSAGE ARRIVES
                            │
                            ▼
                        WebSocket
                            │
                            ▼
                        Update Cache
                            │
                            ▼
                        ┌──────────────┐
                        │ Message List │
                        └──────────────┘

        So the architecture is:
                        Initial Data → REST API
                        Live Data → WebSocket
